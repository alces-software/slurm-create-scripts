## Setup
Create a blank alma 10 vm using the [vm creation script](https://github.com/alces-software/generate-vm/tree/main).
if you are creating the login node give it external and internal network access.
if you are creating the compute nodes only give it internal network access.
run the scripts on the vms and answer the prompts and it will automatically create a login node and compute nodes for you.
run ```su - clusteruser``` to login to the clusteruser account.
